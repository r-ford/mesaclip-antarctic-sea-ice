This repository contains two notebooks that recreate the analysis in the manuscript Ford and Rose (submitted 2026 to TC). In order to run the notebooks, you will need to download the data described in the data availability statement:

- Regridded versions of the CESM1.3 SIC and SST data were downloaded via a Globus Guest Collection, which was accessed at https://usclivar.org/meetings/high-resolution-modeling-data-access
- The MESACLIP data can also be downloaded from NCAR's GDEX (see paper for dataset IDs), but they will be on the native grid, not the 1x1 grid used here
- The NSIDC dataset was downloaded from https://nsidc.org/data/g02202/versions/6
- The OSI SAF datasets were downloaded from https://cds.climate.copernicus.eu/datasets, the Copernicus Climate Change Service Climate Data Store (see paper for dataset IDs)
- The HadISST1 SIC dataset was downloaded from https://www.metoffice.gov.uk/hadobs/hadisst/data/download.html.
